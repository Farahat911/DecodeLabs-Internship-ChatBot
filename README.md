# Rule-Based AI Chatbot (CLI)

A lightweight, high-performance Rule-Based Chatbot built in Python. Developed as Project 1 for the DecodeLabs Artificial Intelligence Internship.

## 🚀 Features

* **O(1) Time Complexity:** Eliminates `if-elif` ladders by utilizing Hash Maps (Dictionaries) for instant intent matching.
* **Sanitization & Fallbacks:** Includes built-in text sanitization and atomic lookup operations with an automatic fallback mechanism for unknown inputs.
* **Interactive CLI Loop:** Runs a continuous terminal loop for seamless user interaction.

## 🛠️ Tech Stack

* **Language:** Python 3
* **Interface:** Command Line Interface (CLI)

## ⚙️ Installation & Usage

1. **Clone the repository:**
   git clone <your-repository-url>
   cd DecodeLabs-Internship/Project_1

2. **Run the script directly:**
   python main.py

3. **Interact:** Type your messages in the terminal. Type `exit` to shut down the bot.
